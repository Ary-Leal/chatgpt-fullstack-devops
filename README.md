Este repositório contém um projeto fullstack estilo ChatGPT, desenvolvido usando Node.js, React, MongoDB Atlas e Docker.

Principais Pontos Funcionais

Aplicativo fullstack com funcionalidades semelhantes ao ChatGPT
Utilização de Node.js no backend e React no frontend
Integração com o banco de dados MongoDB Atlas
Uso de Docker para containerização da aplicação

Stack Tecnológica

Node.js
React
MongoDB Atlas
